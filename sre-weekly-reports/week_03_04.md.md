# Exporters

## 1. MongoDB Exporter (Percona)
Installed MongoDB Exporter for percona to get metrics for my database. Database usage percentage and also Database availability are very important metrics.
Port is standard 9216. I have also created a user: exporter / exporterpassword to setup the exporter. The user is stored in admin database. The need for it was to expose all metrics that 
were needed for the grafana graphs.
### Install

``` bash
mkdir mongodbpercona
cd mongodbpercona

wget https://github.com/percona/mongodb_exporter/releases/download/v0.49.0/mongodb_exporter-0.49.0.linux-amd64.tar.gz

tar -zxvf mongodb_exporter-0.49.0.linux-amd64.tar.gz
cd mongodb_exporter-0.49.0.linux-amd64/

sudo mv mongodb_exporter /usr/local/bin
```

### Run

``` bash
/usr/local/bin/mongodb_exporter \
  --mongodb.uri="mongodb://exporter:exporterpassword@127.0.0.1:27017/?authSource=admin&authMechanism=SCRAM-SHA-256" \
  --collector.dbstats \
  --collector.collstats \
  --collector.indexstats \
  --collector.replicasetstatus \
  --collector.topmetrics \
  --collector.currentopmetrics  > /dev/null 2>&1 &
```

### Verify

``` bash
curl http://127.0.0.1:9216/metrics
```

## 2. Node Exporter (RAM Metrics)
Installed node exporter just for the RAM metrics that i could not get from the whitebox exporter that we implemented on the app server.
Mem.info exposes total RAM usage so that we can graph the RAM usage percentage.
### Install

``` bash
mkdir node_exporter
cd node_exporter

wget https://github.com/prometheus/node_exporter/releases/download/v1.10.2/node_exporter-1.10.2.linux-amd64.tar.gz

tar xvfz node_exporter-1.10.2.linux-amd64.tar.gz
cd node_exporter-1.10.2.linux-amd64/

sudo mv node_exporter /usr/local/bin
```

### Run

``` bash
node_exporter --collector.disable-defaults --collector.meminfo  > /dev/null 2>&1 &
```

### Verify

``` bash
curl localhost:9100/metrics
```

## 4. Prometheus
 ## Installation
 
 ```
 wget https://github.com/prometheus/prometheus/releases/download/v3.10.0/prometheus-3.10.0.linux-amd64.tar.gz
 tar xvfz prometheus-*.tar.gz
 cd prometheus-3.10.0.linux-amd64/
 vi prometheus.yml
 ./prometheus --config.file=prometheus.yml & > /dev/null 2>&1
 ```
### Main configuration
This is standard prometheus configuration for prometheus to listen to those specific ports for metrics and for the exporters
to expose those metrics.
``` bash
global:
  scrape_interval: 15s
  scrape_timeout: 10s
  evaluation_interval: 15s

rule_files:
  - "rules/*.yml"

scrape_configs:

  - job_name: prometheus
    static_configs:
      - targets: ['localhost:9090']

  - job_name: nodejs_app
    metrics_path: /metrics
    scheme: https
    tls_config:
      insecure_skip_verify: true
    static_configs:
      - targets: ['staging.bestande.ch']

  - job_name: mongodb
    static_configs:
      - targets: ['localhost:9216']

  - job_name: node
    static_configs:
      - targets: ['localhost:9100']

  - job_name: blackbox_ssl
    metrics_path: /probe
    tls_config:
      insecure_skip_verify: true
    params:
      module: [https_cert]
    static_configs:
      - targets:
        - https://staging.bestande.ch/health
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target
      - target_label: __address__
        replacement: localhost:9115
```

### Check targets
Check the targets that prometheus sees and exposes the metrics.
``` bash
curl http://localhost:9090/targets
```

### Grafana queries:
RAM Usage: Uses the Node exporter meminfo metric specifically to measure RAM percentage used.

Application Availability over 30 Days: Uses the Whitebox exporter of the server to measure the average availability percentage over 30 days.

CPU Utilization over time: Uses the Whitebox exporter of the server to measure CPU utilization of each process, MongoDB, Prometheus and the nodejs_app.

Percentage of Database Used: That is a custom graph that shows the amount of database space used. Uses Percona exporter metrics.

MOngoDB Availability over 30 Days: MongoDB dbStats success rate (%) over the last 30 days. Uses Percona exporter.

HTTPS Response Duration: Shows HTTP response duration. It is a sum of all the HTTP request types: (connect, tls, resolve, transfer, processing).
Uses Blackbox exporter.

SSL Expiry Days Left: SSL expiry Days Left, uses Blackbox exporter.



### Prompts used:

Most of the Grafana queries where created using prompting, also used prompting to understand why Node exporter was essential
to expose meminfo used in RAM Usage Percentage graph.

Also in order to understand how the Percona Exporter exposes the metrics by adding --collector.*.

The Prometheus.yml file was also generated by a prompt, but one can also copy paste it from the prometheus documentation.
